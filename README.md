# Kasper Creative Agency Page

An earlier responsive implementation of the Kasper creative-agency interface using HTML and CSS.

## Highlights

- Multi-section landing-page structure
- Responsive layouts and media queries
- Flexbox-based navigation and content alignment
- Portfolio, services, pricing, testimonials, and contact sections
- Custom styling with locally bundled assets

## Built With

HTML5, CSS3, Flexbox, responsive media queries, and Font Awesome.
